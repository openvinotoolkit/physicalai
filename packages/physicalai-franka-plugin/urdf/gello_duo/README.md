# GELLO DUO visualization asset

This mesh-free URDF represents two passive GELLO leaders, each with six rotary
joints and one trigger/gripper degree of freedom. It is a kinematic Studio
visualization, not a dimensionally verified collision model.

Joint order, Dynamixel topology, and trigger semantics are based on the
Apache-2.0 `lerobot_teleoperator_gello` implementation from
<https://github.com/F-Fer/lerobot_ur5e_gello/tree/main/lerobot_teleoperator_gello>.
No geometry assets are copied from that project.
